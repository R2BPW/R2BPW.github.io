Projects

Radio Bargain Bot
Price-intelligence system for the secondary ham radio market. Aggregates listings from 98 sources across 50+ countries, scores each deal using Bayesian bootstrap benchmarks, and publishes verified bargains to 12 regional Telegram channels. Autonomous source discovery via Active Inference. 18+ months in continuous production. GitHub
IR Bridge
Bidirectional infrared bridge from a 1999 Ericsson MC218 palmtop to a large language model. Native OPX drives the IrDA modulator at a baud rate that produces a 38 kHz carrier; Flipper Zero decodes and relays via ESP32 to an LLM API. No cables, no IrDA stack. GitHub
More Fun to Receive
Custom SDR receiver firmware for Xilinx Spartan-6 (OSA103 Mini), written from scratch in Verilog: NCO, hardware-multiplier mixer, decimating CIC filter, UART interface. 200 MSPS. Board pinout reverse-engineered without documentation.
30m QRSS Beacons
Catalogue of identified QRSS beacons on the 30-metre band, maintained from my own grabber station in Moscow.
